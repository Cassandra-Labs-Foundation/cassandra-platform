How this map is made

Open any box to see what is inside it. Solid arrows are static references found in source (imports, table names, routes, the spec's UI surface); dashed arrows are tests, evidence, schedules and runtime callbacks; dotted arrows are reviewed claims, declared order and design-time derivations. One arrow between two frames stands for several; arrows that skip a row appear when you point at or focus a box.

Two layers. The inventory (every container, domain, module, operation, policy and control) is generated by scripts/gen_architecture.py from the API specification, the control catalogue, the hermetic and live test results and the source itself, and regenerates with every artifact rebuild. It states declared facts and static references: an event a module emits, a live flow that names a path. It does not interpret behavior. The traced path follows one large-movement detector into BSA-06 case management, read from source at one revision; its claims are interpretations a human reviewed. Neither layer is a compliance verdict. Tests linked from the traced path are definitions, not runs.
