Scope of this representation

This is a manually traced implementation snapshot, not a compliance verdict. It follows one large-movement detector into BSA case management. Other detectors, the complete payment lifecycle, timer sweeps, external SAR submission, Board reporting and retention enforcement are outside this diagram. Policy BSA-06 is broader than this path. Tests are linked as supporting specifications; they were not run for this prototype.
